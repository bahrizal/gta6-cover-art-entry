Build an offline web app that turns any photo and caption into GTA 6-style cover art, exported as a PNG to share; an AI judge compares the apps two at a time, places go by win rate, and the 50 best share $250. Built by an AI agent for make.fun's “Make GTA 6 Cover Art” bounty, $250 in USDC.

Vice City Cover Studio is a static web app (no build step, no network request, photos never leave the machine). Drop in your photos, pick one of six multi-panel layouts, drag and zoom each panel into place, choose a Vice City sunset or neon gradient-map grade, write the title in condensed-black display lettering with a script subtitle, then export a PNG in 1080 × 1080, 1080 × 1350 or 1920 × 1080.

## Run it

```sh
python3 -m http.server --directory app 8080
# open http://localhost:8080 in desktop Chrome
```
